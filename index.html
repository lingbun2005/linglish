Đưa Linbun Lên Online

Miễn phí & đồng bộ toàn bộ từ vựng + tiền + mèo trắng

Bước 1: Xuất file index.html đóng gói sẵn dữ liệu

Nhấn nút ⬇️ Tải file index.html ở thanh trên cùng. Tệp tải về đã lưu sẵn toàn bộ từ mới, số tiền k và trạng thái Mèo Trắng của bạn.

Bước 2A: Kéo thả lên Netlify Drop (15 giây)

Mở app.netlify.com/drop → kéo thả tệp index.html vào khung trình duyệt để nhận link https://...netlify.app ngay lập tức.

Bước 2B: Đưa lên GitHub Pages

Vào kho GitHub của bạn → Add file → Upload files → tải tệp index.html (giữ đúng tên viết thường index.html) → bấm Commit changes.
